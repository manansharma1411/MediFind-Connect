# System Architecture Documentation

This directory maintains the structural and visual architectural documentation for **MediFind Connect**.

## Key References & Blueprints

1. **Frontend Visual Audit & Screen Specifications:**
   * Refer to `PHASE_0_FRONTEND_AUDIT.md` for the complete 26-screen inventory spanning Patient, Pharmacy, Collaboration, and Intelligence domains.
2. **Domain Architecture:**
   * **Domain 1: Patient Discovery** (Fuzzy search, availability indexing, distance-sorted routing).
   * **Domain 2: Pharmacy Portal** (Inventory CRUD, batch control, low-stock threshold monitoring).
   * **Domain 3: Collaborative Transfer Network** (Peer-to-peer requisition, runner dispatch, digital waybill OTP verification).
   * **Domain 4: Shortage Radar & Intelligence** (Search spike detection, geographic heatmap aggregation, restock suggestions).
